# Data directory

Place the City Hotel dataset at `data/raw/H2.csv`. The raw and processed data directories are ignored by Git by default; do not commit the CSV unless redistribution rights and team policy have been confirmed.

The assignment-provided public mirror is:

- <https://raw.githubusercontent.com/afaq-ahmad/Hotel-booking-demand-Case-Study/master/H2.csv>
- Original dataset article: <https://pmc.ncbi.nlm.nih.gov/articles/PMC6297060/>

The project uses H2 (City Hotel) only. Do not merge H1 into the required experiments. The analysis code does not download data automatically; provide the file locally and verify it with `python main.py validate`.
