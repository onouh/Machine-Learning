# Model artifacts

Generated fitted preprocessing objects and models belong here for local inference and demonstration. They are ignored by Git by default and must not be included in the submission ZIP. Preserve the code/configuration and exact commands needed to regenerate them.

If the team deliberately selects a small artifact for Git tracking, force-add only that file, for example:

```bash
git add -f artifacts/selected-model.joblib
```

Review file size and repository policy before tracking any binary artifact. Never put credentials or private data here.
